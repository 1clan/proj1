# Terminal Trek

A tiny, dependency-free browser CLI game, ready for GitHub Pages.

## Publish

1. Create a GitHub repository and push these files to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/(root)`.
4. Save. GitHub will provide the public Pages URL shortly.

Open `index.html` locally to play during development.
